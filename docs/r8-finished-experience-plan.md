# R8 成品体验改进方案

> 状态说明：R8 已完成操作、反馈、设备提示和辅助功能的功能基线。2026-08-20 的成熟游戏复核将
> 发售级画面、统一 UI、默认操作和动态手感提升为独立的 R9 验收门；后续目标见
> `docs/r9-mature-presentation-plan.md`。本文件保留为 R8 的历史范围和实现证据。

## 1. 目标

R8 不扩充境界、地图或随机刷装，而是把现有“阵灯筑基”纵向切片按成熟桌面 ARPG 的标准重新
整理。目标体验是：传统修仙氛围负责辨识度，暗黑式情境操作负责流畅度，传奇式强反馈负责
可读性。参考的是交互原则，不复制任何第三方素材、界面或数值结构。

完成后的玩家应当在不阅读操作说明的情况下理解三件事：鼠标点哪里会发生什么、一次攻击为什么
成功或失败、当前最值得关注的目标和资源是什么。

## 2. 成品标准

| 层面 | 标准 | 明确避免 |
|---|---|---|
| 操作 | 左键情境移动/追击/互动，直移随时接管；键鼠和手柄均可完整游玩 | 屏幕距离猜测、点击穿透、不可达后静默卡住 |
| 战斗 | 动作阶段、命中、受击、资源不足和首领机制有不同视觉/声音层级 | 全局慢动作、满屏粒子、只靠文字或音效判断 |
| HUD | 战斗时一眼读取自己、目标、六个动作和任务；只显示当前设备提示 | 调试表格、重复信息、任务与 Boss 血条互相覆盖 |
| 画面 | 固定正交镜头下角色轮廓、生态层次、危险范围和路线出口清楚 | 大块无节奏纯色地面、树冠长期挡人、荧光色泛滥 |
| 对话 | 逐字节奏可调，补全与推进分离，选项焦点明确 | 首次按键直接跳过未读句子、等待图标提前出现 |
| 可访问性 | 降低闪烁和命中停顿，不删除必要的战斗信息 | 用“关闭全部特效”换取舒适度 |

## 3. 操作方案

### 3.1 键鼠

- 左键以物理碰撞层区分地表、敌人和 StoryInteractable3D。
- 点地后将落点吸附到 NavigationServer；无法吸附、路径结束或卡死时显示不可达阵纹与 HUD 原因。
- 点敌人后自动寻路到攻击距离并追击；Shift + 左键原地攻击，Ctrl + 左键强制移动。
- 鼠标右键、1、2 使用三个技能，Space 闪避，Q 使用丹药，Tab 循环目标。
- WASD/方向键出现有效输入时立即取消未完成的鼠标导航和追击意图。

### 3.2 手柄

- 左摇杆移动，右摇杆瞄准；A 普攻/互动，X/Y/RB 三技能，B 闪避，LB 丹药，R3 循环目标。
- 目标获取使用 50° 方向锥，保持使用 65° 方向锥，并检查距离、视口和物理遮挡。
- 移动死区、瞄准死区和瞄准灵敏度可保存；按钮与摇杆轴可按设备槽独立重绑。

### 3.3 镜头

- 探索时镜头在移动/瞄准方向轻微前置。
- 战斗时镜头有限偏向当前目标；唯一首领即使没有手动锁定也参与构图，但偏移上限不超过 3.2 米。
- 相机到玩家射线上的树木、幼松和屋檐临时变为 62% 透明；遮挡结束、暂停或离图时恢复。

## 4. 战斗反馈方案

- `ACTION_ACTIVE` 生成普通或强化剑弧；确认 `DAMAGE` 后生成命中火花、角色闪白/红和局部命中停顿。
- 普通敌人受击停顿 45ms，玩家受击 65ms；只暂停当前地图 `battle_motion_3d` 物理节点，不改
  `Engine.time_scale`，UI、对话和应用服务继续运行。
- 闪避生成三层衰减残影；敌人近战前摇使用扩张范围，远程和冲撞使用方向长条。
- “减少闪烁与命中停顿”开启后跳过材质闪白，停顿乘 0.35；剑弧、火花、前摇和声音保留。
- 首领目标卡显示名称、首领身份、体力和失衡剩余时间；世界 Label3D 只做机制瞬时强调。

## 5. UI 与画面方案

### 5.1 HUD

- 左下状态块：境界层数、存活敌人数、体力和真气的文字、数值与色条。
- 底部动作栏：普攻、三技能、丹药、闪避六格；每格同时显示键位、图形字、名称和消耗/冷却状态。
- 顶部目标卡：锁定对象或首领血条；右上任务卡在透明底上保留当前叙事方向。
- 输入设备提示互斥；资源不足、冷却、动作未收和不可达使用 0.85 秒短反馈。

### 5.2 标题、设置与对话

- 标题页使用左侧旅人/世界氛围、右侧纵向菜单；normal、hover、pressed、focus 使用不同边框和底色。
- 设置页在 `640 x 360` 内同时容纳显示、音频、语言、三设备绑定、摇杆调校、对话速度和减少闪烁。
- 对话默认 48 字/秒，可选 32/48/72/120；逐字时隐藏等待图标，补全后显示。

### 5.3 世界画面

- 保持有限山野色板，以旅人绿、阵灯金、真气蓝、敌意橙红作为功能色。
- 角色、NPC 和敌人使用小尺寸轮廓；食炁兽通过体型、背部晶簇与发光色区分。
- 阵灯隘口的 112 米道路按遭遇段落布置树木、幼松、灌木和石块，两侧形成节奏但不侵入主路导航。
- 出口使用原创木牌；文字材质优先级必须保证深色牌面与金色字同时显示。

## 6. 数据与架构边界

- 所有改动位于表现、输入和应用设置层；BattleSession 的固定步规则、GameRun、StoryContext 与
  存档内容结构不因视觉反馈而改变。
- CombatFeedback3D 是当前 MapGameScene 的短生命周期 Node；不保存到 GameRun，不使用全局事件总线。
- SettingsService 的输入格式版本为 3；旧 Q/E/F/R 默认迁移到右键/1/2/Q，其他用户映射保留。
- 地图新增环境仍由 `.tscn` 所有；程序生成地图继续只在编辑期 bake，运行时不执行生成器。

## 7. 验收门

自动门：

```sh
godot --headless --editor --path . --quit
./tools/run_tests.sh
godot --headless --path . -s res://tools/content_cli.gd -- validate --json
godot --headless --path . -s res://tools/map_generator_cli.gd -- validate res://game/roadside/map_generation/roadside_shop_3d_profile.tres --json
godot --headless --path . -s res://tools/map_generator_cli.gd -- validate res://game/roadside/map_generation/herb_slope_3d_profile.tres --json
godot --headless --path . -s res://tools/map_generator_cli.gd -- validate res://game/roadside/map_generation/north_slope_wilds_3d_profile.tres --json
```

视觉门：G6 十一张、G4 八张、R7 十张与 UI 六张截图均为 `640 x 360` Metal 实图。必须人工检查
标题焦点、木牌、对话正文/选项、键鼠/手柄 HUD、命中帧、Boss 冲撞/失衡、两种阵灯结果、两种
道基、十二怪终测和设置页边界。具体文件名见 `docs/visual-acceptance.md`。

R8 完成不代表内容量达到商业游戏规模；它建立的是下一段内容必须遵守的操作、反馈、UI 和视觉
基线。随机词缀、无限刷怪、装备品质、队友 AI、赛季、全局天气与通用 Boss 阶段编辑器继续排除。
